# Library Management System — Windows Forms

A desktop library management application developed with C# and Windows Forms.

## Overview

This project is a Windows desktop application designed to support library management operations through a graphical user interface.

## Tech Stack

- **Language:** C#
- **Framework:** .NET
- **UI:** Windows Forms
- **IDE:** Visual Studio

## Getting Started

1. Clone this repository.
2. Open the solution (`.sln`) in Visual Studio.
3. Restore the required NuGet packages.
4. Build the solution.
5. Run the application.

A personal desktop application development project.
